## 已完成功能

### 核心模块 (9/9)

- ✅ **数据获取模块** (`data_loader.py`)
  - 基于akshare获取期货日线/分钟数据
  - 本地缓存机制（24小时有效期）
  - 数据清洗和预处理

- ✅ **技术指标计算** (`indicators.py`)
  - 均线（SMA/EMA）
  - ATR（真实波动幅度）
  - ADX/+DI/-DI（趋势强度）
  - 自定义指标（阻力触碰次数、相对强度）

- ✅ **突破检测引擎** (`breakout_detector.py`)
  - 三维突破验证：价格+量能+时间
  - 箱体突破识别
  - 二次突破识别

- ✅ **过滤条件模块** (`filter_conditions.py`)
  - 必要条件：趋势+量能+波动率+结构
  - 加分条件：相对强度+多周期共振+二次突破
  - 评分系统（基础分60 + 加分，最低80分入场）

- ✅ **信号生成器** (`signal_generator.py`)
  - 整合检测和过滤
  - 计算入场价格和止损位
  - 动态仓位计算

- ✅ **仓位管理** (`position_manager.py`)
  - 金字塔加仓（30% → 80%）
  - 动态止损（初始止损 → 前低止损 → 移动止损）
  - 分批止盈（50% / 30% / 20%）

- ✅ **回测引擎** (`backtest_engine.py`)
  - 逐K线回放模拟
  - 订单撮合（考虑滑点和手续费）
  - 性能指标计算（夏普、回撤、胜率等）

- ✅ **策略主逻辑** (`strategy.py`)
  - 单品种分析
  - 品种池扫描
  - 实盘信号获取
  - 回测执行

- ✅ **命令行接口** (`main.py`)
  - analyze: 分析单个品种
  - scan: 扫描品种池
  - live: 获取实盘信号
  - backtest: 运行回测

1. ⚠️ **过滤条件较严格**：在测试期间未能通过所有必要条件

## 系统配置

### 核心参数

```python
# 突破参数
LOOKBACK_PERIOD = 20          # 前高周期
BREAKOUT_THRESHOLD = 0.005    # 突破阈值 0.5%
VOLUME_MULTIPLIER = 1.5       # 量能放大 1.5倍

# 过滤参数
ADX_THRESHOLD = 25            # ADX强度
ATR_COMPRESSION = 0.7         # ATR压缩
RESISTANCE_TOUCHES = 3        # 阻力触碰次数

# 仓位管理
INITIAL_POSITION = 0.3        # 初始30%
MAX_POSITION = 0.8            # 最大80%

# 风险控制
MAX_SINGLE_LOSS = 0.02        # 单笔风险2%
MAX_DAILY_LOSS = 0.05         # 单日风险5%
MAX_DRAWDOWN = 0.20           # 最大回撤20%
```

黑色系、化工、农产品、金属、金融期货等流动性好的品种。

## 使用指南

### 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行完整测试
python test_demo.py

# 分析单个品种
python main.py analyze RB0

# 扫描品种池
python main.py scan --symbols RB0,HC0,I0

# 获取实盘信号
python main.py live --top 10 --detail

# 运行回测
python main.py backtest --symbols RB0,HC0 --start-date 20240101
```
