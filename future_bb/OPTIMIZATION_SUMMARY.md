### 优化的参数

#### 1. 突破阈值放宽
```python
BREAKOUT_THRESHOLD: 0.005 → 0.003  # 0.5% → 0.3%
VOLUME_MULTIPLIER: 1.5 → 1.3       # 量能放大要求降低
BODY_SIZE_MULTIPLIER: 1.5 → 1.3   # K线实体要求降低
BREAKOUT_ATR_MULTIPLIER: 0.5 → 0.3 # 突破幅度降低
```

#### 2. 趋势条件优化
```python
ADX_THRESHOLD: 25 → 20  # 趋势强度要求降低
```

**逻辑变化**：
- 原：必须同时满足（多头排列 AND ADX>25 AND +DI>-DI）
- 新：满足3个条件中的2个即可
  - MA5 > MA20（简化的多头排列）
  - ADX > 20
  - +DI > -DI

#### 3. 波动率条件放宽
```python
ATR_COMPRESSION: 0.7 → 0.8   # 压缩阈值放宽
ATR_EXPANSION: 1.2 → 1.15    # 扩张要求降低
```

**逻辑变化**：
- 原：必须同时满足（压缩 AND 扩张）
- 新：满足以下任一条件即可
  - ATR压缩
  - ATR扩张
  - ATR在合理区间（均值的50%-150%）

#### 4. 结构质量优化
```python
RESISTANCE_TOUCHES: 3 → 2  # 阻力触碰次数降低
容差: 2% → 3%              # 触碰判定更宽松
```

**逻辑变化**：
- 原：必须阻力位触碰3次
- 新：满足以下任一条件即可
  - 阻力位触碰2次
  - 有连续3日上升趋势

#### 5. 评分系统调整
```python
BASE_SCORE: 60 → 70        # 基础分提高
MIN_ENTRY_SCORE: 80 → 70   # 最低入场分降低
```

**效果**：只要通过必要条件，基础分就能达到入场要求

## 优化策略

### 核心思路
从"严格筛选高质量信号"调整为"适度放宽，保持合理过滤"

### 优化原则
1. **多条件OR逻辑**：从"必须全部满足"改为"满足大部分即可"
2. **阈值放宽**：降低10-30%的数值要求
3. **容差增加**：提高判定的灵活性
4. **基础分提升**：让通过过滤的信号更容易入场

### 风险控制
虽然信号量增加，但仍保留核心过滤：
- ✅ 必须有价格突破
- ✅ 必须有一定量能
- ✅ 必须有趋势或结构支持
- ✅ 必须有合理的波动率
