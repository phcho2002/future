# 突破交易量化系统设计规划

## 一、系统目标

构建基于**突破信号**的期货量化交易系统，通过多维度过滤提高胜率，通过仓位管理优化收益率。

**核心理念**：
- 只做高确定性突破（胜率目标 60%+）
- 用仓位管理放大盈亏比（目标 1:5+）
- 信任趋势，让利润奔跑
- 永远警惕反转，保护利润

## 三、突破定义（三维验证）

### 3.1 价格维度（结构突破）
- **前高突破**：价格突破近N根K线的最高价
- **箱体突破**：突破整理区间的上边界
- **动态阻力**：突破关键均线（MA20/MA60）

**量化指标**：
```python
close > highest(high, N) * (1 + threshold)
```

### 3.2 量能维度（动力确认）
- 突破时成交量 ≥ 20日均量 * 1.5
- 持仓量增长（期货特有）

**量化指标**：
```python
volume > MA(volume, 20) * 1.5
open_interest > open_interest[1]
```

### 3.3 时间维度（有效性验证）
- **收盘价确认**：收盘价站稳突破位
- **不回头确认**：突破后3根K线不破突破点
- **加速确认**：突破K线实体 ≥ 近20根平均实体 * 1.5

**量化指标**：
```python
close > breakout_level
low[0:3] > breakout_level  # 3根K线不破
body_size > MA(body_size, 20) * 1.5
```

## 四、过滤条件（提高胜率）

### 4.1 必要条件（AND逻辑）

#### 条件1：趋势背景
```python
# 多头排列
MA5 > MA10 > MA20 > MA60

# ADX趋势强度
ADX > 25 and +DI > -DI
```

#### 条件2：量能确认
```python
volume > SMA(volume, 20) * 1.5
open_interest > open_interest[1]  # 期货持仓量增长
```

#### 条件3：波动率状态
```python
# 突破前压缩
ATR(14) < SMA(ATR(14), 20) * 0.7

# 突破时扩张
ATR(14)[0] > ATR(14)[1] * 1.2
```

#### 条件4：结构质量
```python
# 阻力位至少触碰3次
resistance_touches >= 3

# 突破幅度 > 0.5 ATR
close - resistance > ATR * 0.5
```

### 4.2 加分条件（优先级排序）

#### 加分1：相对强度（+20分）
```python
# 品种涨幅 > 板块平均涨幅
relative_strength = (close / close[20] - 1) > sector_avg_return
```

#### 加分2：多周期共振（+30分）
```python
# 日线 + 小时线同时突破
daily_breakout and hourly_breakout
```

#### 加分3：二次突破（+25分）
```python
# 第一次突破失败，缩量回踩，再次放量突破
volume[回踩] < volume[首次突破] * 0.6
volume[再突破] > volume[首次突破] * 1.2
```

## 五、信号生成逻辑

### 5.1 做多信号

**入场条件**：
```
突破定义（三维验证）
AND 趋势背景（多头排列 + ADX>25）
AND 量能确认（放量 + 持仓增长）
AND 波动率（先压缩后扩张）
AND 结构质量（充分蓄势）
```

**优先级评分**：
```python
score = base_score(60分)
      + 相对强度(+20)
      + 多周期共振(+30)
      + 二次突破(+25)
      + 其他加分项

# 只做评分 ≥ 80分的信号
```

### 5.2 出场信号

**止损**：
- 初始止损：突破点下方 1 ATR
- 盈利后：前低止损
- 趋势跟踪：移动止损（保护利润）

**止盈**：
- 不设固定目标位
- 趋势反转信号：
  - 价格破前低
  - ADX < 20
  - +DI < -DI（多空线交叉）
  - 5日线下穿20日线

## 六、仓位管理（金字塔加仓）

### 6.1 分级入场

```
初始仓位：30%（突破确认）
├─ 加仓1：+20%（回踩不破支撑，止损上移至突破点）
├─ 加仓2：+20%（创新高且量能持续，止损移至盈亏平衡点）
└─ 加仓3：+10%（加速突破，趋势确认，止损保护80%利润）
```

### 6.2 加仓条件

- **必须盈利**：只在浮盈时加仓
- **止损上移**：每次加仓后提高止损位
- **总仓位上限**：80%（预留20%应对反转）

### 6.3 分批止盈

```
50%仓位：走出 2倍止损空间（锁定利润基础）
30%仓位：走出 5倍止损空间（大趋势收益）
20%仓位：趋势反转信号出现（吃尽最后一段）
```

## 十一、风险说明

### 11.1 系统性风险
- **趋势反转风险**：突破后市场反转，系统需及时止损
- **假突破风险**：虽有多重过滤，仍无法完全避免
- **滑点风险**：极端行情下滑点可能大于预期

### 11.2 技术风险
- **数据质量**：akshare数据可能有延迟或错误
- **过拟合风险**：参数优化需谨防过拟合历史数据
- **执行风险**：实盘与回测存在差异

### 11.3 风控措施
- 单笔最大亏损限制：2%
- 单日最大亏损限制：5%
- 最大持仓品种数：5个（分散风险）
- 强制平仓条件：总资金回撤 > 20%
