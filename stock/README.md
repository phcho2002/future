# N型主升浪交易系统

> **核心理念**：潜伏主升浪 —— 在周线级别识别"N型"结构，捕捉主力洗盘后的主升行情。

## 📖 策略概述

### 什么是 N 型主升浪？

N型结构是经典的技术形态，由三个关键点组成：

```
 价格
  ↑
  |                    ┌─ 主升浪启动（第三波）
  |                   ╱
  |          H1 ──── ╱
  |         ╱  ╲    ╱
  |        ╱    ╲  ╱
  |       ╱      ╲╱  ← L2（回调低点，高于L1）
  |      ╱
  |  L1 ╱
  |
  └──────────────────────────→ 时间

  L1: 盘整底部   →   充分调整后的低点
  H1: 首波高点   →   初次拉升的峰值（试盘+建仓）
  L2: 回调低点   →   洗盘完成，缩量回踩（> L1，更高低点）
  突破 H1        →   主升浪启动信号！
```

### 四阶段过程

| 阶段 | 名称 | 特征 | 量价关系 |
|------|------|------|----------|
| ① | **底部盘整** | 低波动、窄幅震荡、均线粘合 | 缩量、地量 |
| ② | **首波拉升** | 放量突破盘整区，涨幅≥10% | 放量上攻 |
| ③ | **回调洗盘** | 缩量回踩斐波那契 0.382~0.618 | 缩量至地量 |
| ④ | **主升浪启动** | 放量突破 H1，均线多头排列 | 倍量突破 |

## 🎯 实战操作流程

### 入场前检查清单

```
□ 周线图上出现完整的 N 型结构（L1→H1→L2）
□ L2 > L1（更高低点确认上升趋势）
□ 回调幅度在 38.2%~61.8%（黄金分割区）
□ 回调期间缩量（主力锁仓，卖压耗竭）
□ 均线多头排列（EMA10 > EMA20 > EMA50）
□ RSI 在 40-75 区间（动能健康）
□ 突破 H1 时放量（≥1.3倍均量）
□ 信号评分 ≥ 65 分（A级以上）
```

### 入场方式

| 方式 | 操作 | 适用场景 |
|------|------|----------|
| **突破买入** | 价格放量突破 H1 时买入 | 稳健型（确认突破） |
| **预埋单** | 在 H1 上方 1-2% 设条件单 | 避免错过快速突破 |
| **回踩确认** | 突破后回踩 H1 不破买入 | 稳健型（二次确认） |

### 止损设置

```
初始止损 = max(入场价 - ATR × 2,  L2回调低点)

首波风险量 = H1 - L2
止损不应超过首波风险量的 15%
```

### 止盈策略

```
TP1（平仓50%）: 入场价 + 风险量 × 2.0（RR=2）
TP2（平仓50%）: 入场价 + 风险量 × 3.5（RR=3.5）

达到TP1后 → 剩余仓位启用移动止损
移动止损 = 最高价 - ATR × 3
```

### 出场条件

1. **保本出场**：达到 TP1 后，止损提到成本价
2. **移动止损**：ATR追踪，保护利润
3. **MA破位**：EMA10 下穿 EMA20，且收盘在 EMA20 下方
4. **结构失效**：收盘跌破 L2 回调低点
5. **时间止损**：入场后 N 周未达目标（周线建议 8-13 周）

## 🔬 回测建议

### 推荐设置

| 设置 | 建议值 |
|------|--------|
| 时间周期 | **周线 (W)** |
| 初始资金 | 100,000 |
| 仓位模式 | 风险百分比（2%/笔） |
| 手续费 | 0.03%（A股）/ 0.1%（美股） |
| 滑点 | 2-5 ticks |
| 回测周期 | ≥5年（含牛熊周期） |

### 品种选择

- **A股**：沪深300成分股、中证500（趋势性好的品种）
- **美股**：标普500成分股（流动性好）
- **避开**：低价股、ST股、日均成交额 < 1亿的品种

### 优化优先级

1. **回调幅度**（斐波那契范围）—— 对胜率影响最大
2. **首波最小涨幅** —— 过滤假突破
3. **成交量倍数** —— 确认主力参与度
4. **均线周期** —— 适应不同市场节奏
