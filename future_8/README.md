# future_8 — 假突破反转系统

> 昨天做突破被假突破打脸 → 今天反过来**赌突破失败**，在被套的突破交易者止损时反向开仓。

## 策略逻辑

- **空头（Upthrust）**：左侧明显下跌 → 反弹 → 向上**假突破阻力**（刺穿后收回 + 阴线放量）→ 做空
- **多头（Spring）**：左侧明显上涨 → 回落 → 向下**假跌破支撑**（刺破后收回 + 阳线放量）→ 做多

这是 **反趋势入场**（counter-trend at a failed re-test），与顺势突破（future_1）天然对家。
二者应在**同一关键位出现、但方向相反**——这也是验证系统正确性的方法。

## 信号管线

```
add_indicators(df)               → ATR(14), 成交量均线
detect_trend(df)                 → 趋势闸：N根累计跌幅 + 反弹中 + 趋势未破
detect_volume_zones(df)          → 成交量加权密集区（支撑/阻力）
nearest_resistance/support       → 取当前价上方/下方最近密集区
detect_upthrust / detect_spring  → 假突破检测：刺穿 → 收回 → 三档失败打分
```

三个核心设计选择（见 PLAN.md）：
1. **趋势闸用"波峰波谷(swing)结构"**：判定最近 N 个波峰是否逐步递降、波谷是否逐步递降（LH+LL = 下降趋势），或镜像递升（HH+HL = 上升趋势）。比初版"N根累计跌幅"更本质——后者只看首尾两点，分不清真趋势和波段回归。下降趋势+反弹中 → 允许做空 setup；上升趋势+回落中 → 允许做多 setup。检测算法借鉴 `future_3/indicators.py` 的对称窗口极值检测。
2. **关键位用"成交量加权密集区"**：借鉴 future_6 的直方图+局部峰值算法，但统计对象改成 `weights=volume` 的价格直方图（真正的高成交堆积带），bin 宽 = ATR×0.75，脱离 Renko 依赖。
3. **回测信号"触发后N根内有效"**：更贴近实盘（你不会刚好在触发那一秒看到），样本量也更大。

## 突破失败分档打分

"突破失败"不是单一布尔判定，而是按强度分三档（可叠加，满分100）：

| 档位 | 特征 | 量化判定 | 分值 | 性质 |
|------|------|----------|------|------|
| **A 快速反击** | 突破后第1根就被明显反击 | break 后第1根就是反向K、实体 ≥ `recoil_atr`×ATR 且收回关键位 | 40 | 最弱但最早 |
| **B 不创新极值** | 之后5根不能创新高/低 | `post_break_bars` 内未再出现超过 break 极值的新极值 | 30 | 中间档 |
| **C 2B 跌破突破点** | 真正冲一段再跌破突破点 | 收盘不仅收回关键位，还越过突破起始点 `beyond_atr`×ATR | 30 | 最强但最晚 |

用 `min_failure_score`（默认40=至少命中A档）过滤弱失败。信号取窗口内 `failure_score` 最高的 setup。

### 改进历程对比（10品种）

| 版本 | 趋势闸 | target_atr | 交易数 | 盈亏 | 均PF | 盈亏比 | 盈利品种 |
|------|--------|------------|--------|------|------|--------|----------|
| v0 旧 | 累计跌幅 | 2.0 | 2386 | −92,309 | 0.69 | 0.90 | 0 |
| v2 新 | swing(n=2) | 4.0 | 2621 | −76,380 | 0.93 | 2.01 | **1 (PP0)** |

**关键发现**：
- **swing 结构闸明显优于累计跌幅闸**：PF 0.69→0.93，盈亏比 0.90→2.01
- **PP0 已盈利**（PF 1.14），呈现反趋势策略应有形态：低胜率(30%) + 高盈亏比(2.70)
- **AU0/MA0/FU0/EG0 拖后腿**：AU0 盈亏比 0.88 是异常值（黄金，点值大、滑点成本占比高）
- 离整体盈利还差一步：均PF 0.93 → 需到 1.0+

**下一步优化方向**：
1. **按品种适配点值/滑点**：AU0(黄金1000元/点)等大点值品种当前用默认 multiplier=10，回测失真，应按品种表设正确乘数
2. **筛选适用品种**：PP0/V0/BU0/TA0(RB0) 这类盈亏比>1.8 的品种更有潜力，AU0/FU0/EG0 可能不适合此策略
3. **target_atr 继续推进**：6.0 时 5 品种 PF 曾达 0.95，需配合正确乘数重测
4. **参数网格**：对 `n_swings`/`swing_lookback`/`pullback_atr`/`break_atr` 做网格

## 设计笔记

- **已移除 RSI 过滤**：威科夫原版用 RSI 超买/超卖过滤，但在"趋势后假突破反转"语境下反弹往往刚把 RSI 拉回中轴，门槛过严会滤掉大量 setup，故直接移除，改由趋势闸 + 成交量确认把关。
- **突破失败分档打分**：A快速反击(40) + B不创新极值(30) + C-2B跌破(30)，满分100。打分逻辑在 `signal.py:_score_failure_short/long`，参数在 `config.yaml` 的 `score_*` / `min_failure_score` / `recoil_atr` / `beyond_atr`。
- **目标位**：取 ATR 目标与下一个密集区中心的较保守值，偏向更早止盈。
- **止损**：放在假突破 K 线的极值点（Upthrust 放刺穿高点、Spring 放刺破低点），天然风报比较好。
